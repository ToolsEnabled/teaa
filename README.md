# TEAA

TEAA (ToolsEnabled Agent Architecture) provides Fleet, ToolsEngine, and Knowledge through one local MCP connection.

## Install

Download a platform package from the [GitHub releases page](https://github.com/ToolsEnabled/teaa/releases) and run the installer included with it.

To install from source, clone this repository and run `./install.sh` on Linux or `scripts/install.cmd` on Windows. Node.js 22.19 or newer is required; Windows also requires Python 3.11 and Git for Knowledge repository operations.

See [SETUP.md](SETUP.md) for configuration and first-run details.
